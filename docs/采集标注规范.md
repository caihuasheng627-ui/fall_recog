# 采集与标注规范

三人一起采。每次只做一种动作，做完站稳 5 秒再停止记录。动态动作从第 3 秒开始，前 3 秒站好，避免把准备动作标进去。`motion_onset_ms` 就填这个开始时刻，站立和空房间留空。

跌倒和主动躺下只在垫子上做，旁边要有人保护。

| label | 动作 | 一次记录里怎么做 |
|---|---|---|
| `empty` | 空房间 | 人全部离开，至少 20 秒 |
| `stand` | 站立 | 在检测区内站稳 |
| `walk` | 走动 | 沿雷达正前方来回走 |
| `sit` | 坐下 | 从站立坐下，坐稳后保持 |
| `bend` | 弯腰 | 站立弯腰再站直，重复 3 次 |
| `lie` | 主动躺下 | 慢慢躺到垫子上，躺稳保持 |
| `fall` | 跌倒 | 在垫子上由站立失去平衡倒下，倒地后保持不动至少 15 秒 |

`lie` 和 `fall` 必须分开标。主动躺下是正常动作，跌倒才是要报警的动作。

每个人都要覆盖上面 7 种动作。记录表写清人员、身高、距雷达大约几米、雷达架高、朝向、垫子、`train` 还是 `test`。

训练和测试按完整动作记录分开。`P01` 的全部记录只进测试，调阈值时不看这些文件。其余人员进训练。不要把同一次记录切一半做训练、一半做测试。

实板数据到达之前，仓库里的 `data/synthetic` 只用于把程序跑通。那些数字不能写进实验结论。实板 CSV 不要填写 `hgt`，固件帧里没有身高。

# 规范动作测试集（合成，P01）

本报告来自合成数据管线自检，用来确认程序、文件格式和事件接口。表里的数字不是实板跌倒识别准确率。实板 CSV 放到 data/board 后，用同一条 eval 命令重跑。

判定看记录结束时的状态。中途进过疑似或报警、最后回到正常的，记为正常。结束时仍是疑似、没有升级，记为「仅疑似」。

## 参数

- 丢掉 rng 或 vel 等于 -999 的帧
- 快速冲击 |vel| ≥ 90（单位与 CSV 的 vel 相同，当前假定 cm/s）
- 冲击需在 600 ms 内至少出现 2 帧，且距离沿速度方向变化 ≥ 30（假定 cm）
- 距离回到冲击前 20 以内，或从落点向冲击前回升 ≥ 25，取消冲击。沿冲击方向继续移动不取消
- 静止 |vel| ≤ 15（不要求贴在落点 20 以内）
- 静止 3000 ms 进入疑似，8000 ms 升级为报警
- 帧里有 hgt 时，还要相对冲击前下降 ≥ 40，且当前高度 ≤ 50（假定 cm）。没有这一列时不查高度
